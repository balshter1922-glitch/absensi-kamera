      Privasi & Penyimpanan

      • Data wajah diproses dan disimpan secara lokal pada perangkat ini.
      • Jangan gunakan perangkat bersama untuk menyimpan data wajah siswa tanpa izin yang sesuai.
      • Penggunaan data biometrik harus mengikuti kebijakan sekolah dan peraturan yang berlaku.
      • Menghapus data browser atau LocalStorage dapat menyebabkan data registrasi wajah hilang.
      • Data tidak tersinkronisasi antar perangkat. Tidak ada backup server.
      • Mode penyimpanan: Local Device.

      Pengaturan Data

      Kelola data lokal pada perangkat ini.

      Semua data siswa, descriptor wajah, dan data absensi lokal akan dihapus dari perangkat. Tindakan ini memerlukan konfirmasi berlapis.

      Keterbatasan Sistem

      • Data siswa hanya tersedia di browser/perangkat ini.
      • Data wajah tidak otomatis tersedia di perangkat lain.
      • Data absensi tidak tersinkron antar komputer.
      • Tidak ada autentikasi: siapa pun dengan akses ke perangkat dapat berinteraksi dengan data lokal.
      • Untuk akses kamera, browser dapat memerlukan HTTPS atau localhost.
